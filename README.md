Armor Detector - 装甲板检测系统
项目概述

Armor Detector 是一个基于ROS2和OpenCV的实时装甲板检测系统，专为RoboMaster机器人竞赛设计。该系统能够从摄像头图像中检测敌方机器人的装甲板，并进行精确的位姿估计。
主要特性

    🎯 高精度检测：基于灯条匹配的装甲板检测算法

    📍 实时位姿估计：集成PnP解算，提供3D位置信息

    🎨 多颜色识别：支持红、蓝、白色装甲板检测

    🔄 坐标系转换：自动处理OpenCV到RViz坐标系转换

    📊 性能统计：实时显示处理帧率和检测统计

    🎮 优先级排序：按匹配得分对检测目标进行排序

    ⚙️ 参数可配置：支持ROS2参数动态配置
